Flows can scroll until an element is on screen, `scroll: { direction, until: <selector> }`, and press a key with modifiers held, `pressKey: { code, modifiers: [shift|ctrl|alt|meta] }`. The existing forms are unchanged. MCP `run_flow` accepts both.
